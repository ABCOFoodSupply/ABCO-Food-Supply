# ABCO Food Supply (AFS) - B2B Food Supply Web Application

A pixel-perfect Next.js web application implementing the ABCO Food Supply design for food trading & distribution across the Kingdom of Saudi Arabia.

## Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Toast Notifications**: Sonner
- **Typography**: Inter Font

## Features & Sections Included
1. **Top Bar**: Quality Food assurance, Jubail location, direct email, and social channels.
2. **Main Header**: Stylized AFS brand logo, interactive navigation menu, product category dropdown, Search bar, Red Enquiry pill button, and Green WhatsApp button with mobile drawer.
3. **Hero Section**:
   - Primary headline: *"Your Trusted Partner for Quality Food Supply"*
   - 4 Feature Badges: Wide Product Range, Reliable Supply Chain, Timely Delivery, Competitive Pricing
   - CTA buttons: *"Buy Any Products"* and *"Enquire Now"*
   - Vision 2030 official seal & *"Quality Food for a Better Tomorrow"* badge overlay
   - Quick category pills for 9 food categories
4. **About Us Section**:
   - Company background, mission overview, "Learn More" CTA
   - Modern logistics distribution center visual
   - 4 Circular Stat counters: 500+ Food Products, Trusted Global Suppliers, Reliable Supply Chain, Serving Across Saudi Arabia
5. **Our Products Section**:
   - 12 comprehensive food categories with high-definition imagery and hover zoom
   - "View All Products" button and interactive selection
6. **B2B Promotion Banner**:
   - "Buy Any Food Products for Your Business Needs"
   - Highlights: Bulk Supply, Best Prices, Quality Assured
   - "Shop Now" CTA
7. **Our Services**:
   - Import & Distribution, Procurement Support, Logistics Coordination, Fleet & Transport, Custom Packaging
8. **Why ABCO Food Supply**:
   - 8 Core Value Pillars
   - 3-Column Mission, Vision, and Values cards
9. **Clients & Partners**:
   - Leading Saudi hypermarkets: Carrefour, LuLu, Panda, BinDawood, Danube, Al Othaim with carousel navigation
10. **Get In Touch & Location**:
    - Direct phone, email, headquarters address, and social links
    - "Send Us an Enquiry" form with validation and Sonner toast notifications
    - Interactive Jubail location card and map widget with zoom controls
11. **Footer**:
    - 5-column breakdown with Quick Links, Services, Products, Contact details, and Copyright note
12. **Enquiry Modal**:
    - Interactive wholesale requisition popup

## Getting Started

Run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

To build for production:
```bash
npm run build
npm start
```
